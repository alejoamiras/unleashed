# Lessons

What already bit this repository, one line each, linking to the detail. Read it first; keep it under 8 KiB; retire an entry a newer one supersedes.

- A new worktree lacks the gitignored `contracts/bridge/evm/{lib,out,cache}`, so the sandbox cannot boot: run the README's pinned `forge install` lines, each with `--no-git` (else a commit ships gitlinks), or copy `lib/` only; a copied cache names the other checkout ([phase 4](archive/unleashed-reskin/lessons/phase-4.md)).
- A native TXE oracle crash (`Napi::Error`) mid-suite turns every later hub test into "Failed calling external resolver": re-run that block alone before suspecting code.
- Tree-mode `git grep` skips symlink blobs; a scan of every byte a push sends reads the objects (`git cat-file --batch`), replacement refs off.
- A fake that holds an async call forever never meets the races its writes open: let it write first ([a6](archive/sdk-1/lessons/phase-6.md)); a lock holder must load before the write under test ([journal-2](archive/journal-2/lessons/phase-1.md)).
- Under `set -o pipefail`, `producer | grep -q` can SIGPIPE the producer: capture its output, then grep it.
- Vite inlines assets under `assetsInlineLimit` (4096 B) as `data:` URIs, font subsets included: keep the build's guard ([phase 1](archive/unleashed-reskin/lessons/phase-1.md)).
- `--ul-notch` inherits, so every notch host declares both `--ul-fill` and `--ul-notch`; the fill is an absolute `::before` on the padding box, so a notch host cannot scroll ([phase 3](archive/unleashed-reskin/lessons/phase-3.md)).
- A universal `prefers-reduced-motion` rule has zero specificity: any component `animation` beats it without `!important` ([phase 2](archive/unleashed-reskin/lessons/phase-2.md)).
- `EmbeddedWallet.create` without `ephemeral` persists a 15 MB store to `./aztec-wallet-data`, untracked and not gitignored ([phase 9](archive/unleashed-reskin/lessons/phase-9.md)).
- `gh stack sync` fast-forwards the local trunk, so with `main` checked out in another worktree deliver with `gh stack push` and `gh stack submit`; `submit --auto` opens drafts unless given `--open`.
- After a stack push, an aggregator can read FAILURE from the run the push cancelled until its replacement reports: check that run before re-running.
- A watcher runs before an awaiting caller resumes (a released `ref` hold, a locked reload): re-check guards after it; set what it reads in the span ([1](archive/send-copy-1/lessons/phase-1.md), [2](archive/journal-1/lessons/phase-0.md)).
- Vue's whitespace condensing drops a space at the edge of conditional text ("accountmain"): put it inside the interpolation (``{{ q ? ` ${q}` : "" }}``) ([phase 15](archive/aprime-fidelity/lessons/phase-15.md)).
- A component rendered in a parent's template, slots included, carries the parent's scope id, so its scoped rules reach it; jsdom runs no styles, so pin that in a browser ([phase 4](archive/aprime-fidelity/lessons/phase-4.md)).
- Most screen readers do not announce a live region (`aria-live`, `role="log"`) inserted with its text: mount it empty and unconditionally, then fill it ([phase 19](archive/aprime-fidelity/lessons/phase-19.md)).
- A lookup keyed by wallet- or user-supplied text is a `Map`, never an object literal, or `constructor` and `toString` resolve through the prototype ([phase 5](archive/aprime-fidelity/lessons/phase-5.md)).
- A component with a `document`-level key listener needs `attachTo: document.body` and `enableAutoUnmount(afterEach)` in tests, or earlier cases swallow Tab and Escape ([phase 8](archive/aprime-fidelity/lessons/phase-8.md)).
- `signal-exit` (via bb.js) re-raises a signal it is alone on and `bun run` forwards a second SIGTERM, so keep reap handlers on `process.on` with an idempotent stop, or children such as anvil are orphaned ([phase 4](archive/aztec-v6/lessons/phase-4.md)).
- A per-run wallet store starts empty: register every instance a script simulates against, or the PXE answers "No artifact registered" ([phase 6](archive/aztec-v6/lessons/phase-6.md)).
- Across's `deposit` bounds a quote's age (`depositQuoteTimeBuffer`), not its `fillDeadline`, so missing logs never prove not-sent: end a lost-deposit search at `fillDeadline + buffer` ([phase 11](archive/lifi-routing/lessons/phase-11.md)).
- LI.FI's Executor is permissionless, so candidates keyed on a send's public calldata can be crowded for good: key them on what only the real delivery carries (EndpointV2's unindexed `ComposeDelivered` guid) ([D54](archive/lifi-routing/plan.md)).
- Across's testnet relayer under-gasses message fills into recovery, and Across testnet repays and refunds nothing: our `testnet-relayer` Worker fills testnet sends alone; one it misses stays in the source pool ([relayer-1](archive/relayer-1/plan.md)).
- Base Sepolia's blocks went from 2 s to 0.2 s, and its timestamps repeat: find a scan window by timestamp search, never a block count ([relayer-2](archive/relayer-2/plan.md)).
- Chain facts the app trusts come through the build's pinned read RPCs, never the wallet's transport, which answers for the wallet's chain ([phase 9](archive/lifi-routing/lessons/phase-9.md)).
- Anvil can answer a send before its block is queryable: wait for the receipt, never read once ([phase 9](archive/lifi-routing/lessons/phase-9.md)).
- Overlapping runs held at their first broadcast sign one transaction at one nonce, proving nothing about interleaving: hold a run at a named write (`functionName`) ([phase 5](archive/relayer-1/lessons/phase-5.md)).
- Bun accepts `fetch` options workerd rejects (`redirect: "error"`: use `"manual"`), and a `wrangler deploy --dry-run` bundle test executes nothing: assert exact options in unit tests, checked against workerd's docs (wrangler 4.129.1, [a3](archive/relayer-1/lessons/phase-a3.md)).
- Workers Builds' import opens a pull request (automatic configuration) when its root directory has no Wrangler file: set it to the app's own directory ([phase 6](archive/landing/lessons/phase-6.md)).
- Software-rendered WebKit here starves past about eight parallel pages or under load, failing other canvas-timing cases each run: compare a control host ([phase 7](archive/landing/lessons/phase-7.md)).
- A Single Redirect runs before a Worker custom domain, so attach under a live rule and toggle it; only `PUT …/workers/scripts/<name>/domains/records` with `override_existing_dns_record` replaces a DNS record ([phase 7](archive/landing/lessons/phase-7.md)).
- A custom domain needs account-wide Workers Scripts Edit and zone Workers Routes Edit (no per-Worker role); a token's dashboard expiry is 00:00 UTC of a day, so deleting it is the real limit ([phase 7](archive/landing/lessons/phase-7.md)).
- The keyed Sepolia RPC can answer a read after a receipt from a backend behind that block, stopping the conductor on a landed write that a re-run adopts only for factory, hub and portals: retry only on the lag's messages ([6.0.0](archive/aztec-6-stable/lessons/phase-11.md)).
- An Aztec Inbox message's gas depends on the state it lands in (6.0.0: an L1 block's first message opens a bucket), so a bare estimate can run out a block later: pad Inbox writers ([phase 8](archive/aztec-6-stable/lessons/phase-8.md)).
- A keyed `verify-l1 --strict` rebuilds `contracts/bridge/evm/out`, so an overlapping sandbox or forge build hits `ENOENT` ([phase 12](archive/aztec-rc3/lessons/phase-12.md)).
- `readHandle` parses `handle.json` through `sandboxHandleSchema`, and zod drops undeclared keys: declare there every sandbox field the browser fixtures read ([phase 3](archive/aztec-fee-asset/lessons/phase-3.md)).
- `PLAYWRIGHT_BROWSERS_PATH=/opt/ms-playwright` here lacks Playwright 1.63's Chromium: unset it ([phase 3](archive/aztec-fee-asset/lessons/phase-3.md)).
- Bash spills a long here-string or heredoc to a temp file on this host's overlayfs `/tmp`: match output that may hold a keyed URL with `case`, never `grep <<<` ([phase 11](archive/aztec-6-stable/lessons/phase-11.md)).
- Codex's endpoint refuses a prompt framed as attacker role-play: ask the same questions as a defensive review ([gen-pins-1](archive/gen-pins-1/lessons/phase-4.md)).
- solc leaves an unused parameter unnamed: match a hand-written ABI to deployed code by types ([gen-pins-1](archive/gen-pins-1/lessons/phase-4.md)).
