# private-fuel — private Fee Juice across the bridge

**Tier:** `deep` — Novelty HIGH (first private-FJ integration, the Wonderland FPC, the bridge-secret derivation), Security HIGH (privacy + fee payment), Irreversibility HIGH (wrong FPC address / random secret = unrecoverable FJ), External coupling HIGH (Wonderland FPC, version-specific address). Rubric leans mega-deep but the Holonym/Wonderland prior art + the pieces the wallet already ships de-risk novelty. Aztec pinned **4.2.0**. Testnet only. Never main.

**Goal:** a PRIVATE token bridge arrives with gas via the Wonderland PrivateFPC — no L1 address leak. Gas privacy FOLLOWS token privacy (public→public FJ, private→private FJ; the private-token+public-gas combo stays impossible by construction). Ships with the B-presets UI (private default) and removes the "fuel withheld on private" guard. Fee-method matrix: no-fuel → wallet chooses (stop forcing Sponsored); public fuel → `FeeJuicePaymentMethodWithClaim` (fjwc); private fuel → Wonderland `PrivateMintAndPayFeePaymentMethod`.

Sources: three drafts — main · codex · opus (the best-researched; this consolidation adopts its skeleton).

## The mechanism (verified against the repo)
- **Private fuel L1 deposit**: `fuelRecipient = PrivateFPC L2 address`, `fuelSecretHash = computeSecretHash(deriveBridgeSecret(bridgeSecretSalt, claimer))` where `deriveBridgeSecret = poseidon2HashWithSeparator([salt, claimer], DOM_SEP)`, `DOM_SEP = poseidon2HashBytes("az_dom_sep__fpc_bridge_secret") & 0xffffffff === 3952304070`. The L1 `SwapBridgeRouter.bridgeWithFuel` already carries `fuelRecipient`/`fuelSecretHash` witness-bound (`SwapBridgeRouter.sol:89` comment: *"user for public fuel, FPC for private fuel"*). **No Solidity change.**
- **Private fuel L2 claim**: `PrivateMintAndPayFeePaymentMethod(fpc, amount, secret, salt, leafIndex)` → `FeeJuice.claim(fpc,…)` then `PrivateFPC.mint_and_pay_fee(amount, salt, leafIndex)`; the FPC re-derives from `msg_sender`, asserts `amount ≥ max_gas_cost`, credits `(amount − max_gas_cost)` to the user's private internal balance, pays the sequencer.
- **Already shipped (not this arc):** the wallet bundles the PrivateFPC artifact and auto-registers it at `salt=Fr.zero(), deployer=ZERO`; the TS↔Noir secret keystone is proven in the wallet's e2e fixture.
- **The fund-loss bug to fix:** `runSwapBridge` hardcodes `fuelSecret = Fr.random()` (`bridge-core/src/flows.ts:252`) — correct for public (recipient-bound), **fatal for private** (the claimer must reconstruct the secret). Make it injectable.

## Security & Adversarial Considerations
- **Wrong FPC address ⇒ unrecoverable FJ (headline):** derive from the installed `215fd08` artifact only; address tripwire test; live `nodeVersion` check before any fund-moving phase; dust canary on first use + any artifact re-pin; persist the per-deposit `fpc` for post-hoc drift detection.
- **`deriveBridgeSecret` drift ⇒ FJ stranded:** one shared helper + the TS↔Noir↔fixture keystone gates the build. Assert the runtime `DOM_SEP === 3952304070`.
- **Random vs derived secret:** the injected-secret design + a pin asserting the private witness uses `deriveBridgeSecret`, never `Fr.random()`.
- **Privacy — precise claim (double-audit LOW):** private fuel hides the user's AZTEC address (never on L1) and *which* user the gas credits (the FPC is a shared anonymity set), but the L1 `depositToAztecPublic(FPC)` is sent by the user's EOA — the "this EOA funded the FPC by amount X" link IS public on L1. Don't overstate "no L1 leak"; state it precisely in UI copy + Inferences.
- **Privacy invariant:** the private claim MUST self-pay via the private FJ; NEVER Sponsored/public on the private path — including recovery (L11: private recovery is FPC-retry only). P4 asserts no Sponsored touched it + public FJ doesn't increase. There is NO Sponsored fallback anywhere (L7: cold no-fuel claims are BLOCKED, not Sponsored), so no Sponsored path can bleed into the fueled private path.
- **Mid-flight Aztec upgrade (double-audit MED):** the FPC address binds the bytecode+version (classId); a deposit sent before an upgrade + claimed after strands. The L15 runtime check + announced testnet upgrades mitigate; document an abort-window / "don't bridge private fuel near a known upgrade" operational note.
- **Two-salts confusion:** FPC-address salt zero vs per-deposit bridge-secret salt — code comments + a pin that a reused salt is rejected (nullifier collision).
- **Insufficient fuel ⇒ bundled-claim revert with irreversible L1 deposit:** pre-gate `received ≥ estimatedMaxGasCost`; recovery ladder reachable for the private case.
- **Manifest under-scoping ⇒ post-deposit "artifact not found":** scope `claim` + `mint_and_pay_fee` exactly, no wildcards; re-consent via the field-diff.
- **FPC version drift:** an Aztec bump changes the FPC bytecode/address → a silent fund-loss trap; pin + runtime-assert + documented re-derive.
- **Supply chain:** the Wonderland tarball is a GitHub-release pin in `bun.lock` (not npm) — frozen-lockfile CI covers drift; outside the 7-day npm gate (note it).
