## Gotchas (exact strings)

- **The node silently stops sequencing after ~7 blocks.** `stdio: "pipe"` with no consumer fills the 64 KiB pipe and the child blocks on write. Drain BOTH streams.
- **`SEQ_MIN_TX_PER_BLOCK=0` does not mint empty blocks** on 5.2.0 — the chain builds a block per tx, so `getL1ToL2MessageCheckpoint` anchors never advance on their own. `forceBlock` (a public AuthRegistry revoke of a random never-granted witness — needs no contract of ours) per poll, and a heartbeat across `consumeWithdrawal`'s proven wait.
- **`No contract instance found for address 0x…`** — `register_token` enqueues `Token::at(derived).constructor_with_minter`, so the wallet must hold the derived instance BEFORE the tx can be built (the oracle resolves the callee locally). `registerHubToken` first, always.
- **Permit2 `SignatureExpired` (`0xcd21db4f`)** — anvil's timestamp races ahead of wall clock; deadlines come from `getBlock().timestamp`.
- **Permit2 `InvalidSigner` (`0x815e1d64`) on gas-only** — a real bug in `send-flow.ts`: the direct-gas `bridge()` lane signed a witness carrying `fuelSecretHash` (the router zeroes it) and zeroed `aztecRecipient` + `tokenSecretHash` (the router takes the gas recipient and secret as the TOKEN ones). Unsignable — and had it landed, it would have minted Fee Juice to L2 address zero behind an unopenable secret. `buildWitness` now takes the entrypoint; `send-flow.test.ts` pins the shape against the router's field layout.
- **PrivateFPC `Amount too low to cover gas cost`** — the FPC asserts against the COMMITTED `maxFeesPerGas`; the blunt 1e13 setup ceiling prices a budget no slice covers. `predictedWorstMinFees(node).mul(2)` for that lane.
- `nonce too low` from concurrent viem deploys on one L1 account → sequential. `[aztec] Error: Address already in use` prints on every boot and is harmless.
- The 6.5-min smoke was killed mid-flight twice, not by anything in the run; the run's own SIGTERM handler reaped the network cleanly on each kill — no orphans.
- `TxReceipt` exposes `transactionFee` but no `gasUsed`, so the budgets derive from fees, not gas units (the plan's "gas-unit budgets" wording is superseded — fees are what the manifest's `fjPerTx` is spent as).

## Arc-3 quality loop

### Reviewer pass (fresh-context Opus, medium) — 17 findings, all acted upon

The blocker: **`readLeaves` parsed the router's `Bridge`/`BridgeWithFuel` event over the whole receipt** — viem's `parseEventLogs` matches on topic0 only, and the token being bridged runs arbitrary code inside the Permit2 pull BEFORE the router emits, so a hostile ERC-20 could emit a same-signature event with an attacker-chosen leaf index that the journal, the backup and every claim retry would then carry (a vector the any-ERC-20 design newly opens — in v1 the token was ours). Fix: only logs the router emitted count, and exactly one must match (`routerEvent`); pinned by a forged-log test. Should-fixes: `parseManifestV2Strict` had no production caller, so a candidate whose `l2Token` was not the hub's derivation promoted cleanly (now `assertFaucetCandidateShape` is async over both halves); `assertZeroSeed` compared the factory but not the hub, and `verifyGenerationBindings` never read `factory.L2_HUB` (a self-consistent hub built with another class id would promote and never learn a token — both closed); the fuel ladder's `schema >= 2` widening misclassified a schema-3 token-only private send as "private-incomplete" (now `boughtFuel` reads the record's intent); `isRegisterRace` and the sync-retry predicate matched the same ambiguous string (`No non-nullified L1 to L2 message`) with opposite handling — a not-yet-consumable register leaf fell through to a plain claim that failed on the uninitialized binding and escaped the retry loop (now the fallback re-reads `token_for` and only takes the plain path when the hub knows the token, which must also be the journal's `l2Token`); `deployFactory` threw "generation is dead" for a factory that landed ahead of its journal entry (now adopted after `IMPLEMENTATION` + `L2_HUB` agree); `hubExitsPaused` defaulted to "open" on an unrecognized shape (fails closed); `InexactPull` was undecodable; `metadataReturndataBytes` accepted any ABI offset where the sanitizer accepts only `0x20`. Nits: `seedPool` journalled a tx hash it could never read under inherited stdio; a half-set `SANDBOX_*` attach booted a second network silently; a lost registry lock leaked rows without a word; `script-send.ts` and the `bridgeWithFuel` arm of `runSend` had no tests (now 6 + 2 cases: token+gas witness↔calldata mapping, the fuel-only zero-fields shape); one "legacy" in a comment; `logoURI` is https-only.

Reviewer verdict: "witness matches `_hashBridgeWitness` field-for-field across all four intent × privacy × entrypoint combinations … `assertRouteGrammar` is a faithful restatement of `_validateRoute` … both hand-written ABIs match the Solidity and the hub method signatures match `main.nr`; the portal derivation, the register content hash and the word sanitizer are byte-exact mirrors of the factory."

### Codex pass (xhigh, adversarial) — session `01a063f8-c982-7133-bb61-00c100f14850`
