## Summary

One L1 `PortalFactory` mints a **storage-less portal clone per ERC-20** (OZ `Clones` with immutable args) and attests the token's identity + metadata to **one ownerless L2 `TokenBridgeHub`** through an L1→L2 `register` message. The hub **deploys the per-token L2 `Token` itself** from that attestation (Wonderland `vault_deployer` pattern) and serves every claim and exit. The router derives the legal portal from `bridgeToken` per entrypoint (closing A-1) and gains a fuel-only path (swap-in-place gas). bridge-core grows a generation manifest, deterministic derivation with cross-toolchain keystones, per-token journals, route discovery with a first-class `no-route`, and a runtime token list. The tools app becomes a 3-step wizard (Token → Amount → Review) with a per-token wallet grant. Done = testnet live via the new conductor with pre-created fake blue chips + documentation updated everywhere; mainnet is a later owner-run arc behind `/harden security`, and the mainnet build shows a placeholder until then.

Eleven phases (P0–P10) in six work arcs (Arc 0 spike + Arcs 1–5), five stacked PRs (Arcs 1–5).

## Architecture & Implementation

### L1 — `contracts/bridge/evm/src/`

**`TokenPortalImpl`** (`is ReentrancyGuardTransient`; compiled in-project via the `@aztec/` remap). Clone runtime = 65 bytes; the implementation is an ordinary contract.

```solidity
IPortalFactory public immutable FACTORY;   // msg.sender at construction (D7)
IInbox  public immutable INBOX;  IOutbox public immutable OUTBOX;  uint256 public immutable ROLLUP_VERSION;
bytes32 public immutable L2_HUB;
constructor(IRegistry registry, bytes32 l2Hub);            // rollup → inbox/outbox/version as <forked-portal>
function underlying() public view returns (IERC20);        // address(bytes20(Clones.fetchCloneArgs(address(this))))
function depositToAztecPublic(bytes32 to, uint256 amount, bytes32 secretHash) external nonReentrant returns (bytes32 key, uint256 index);
function depositToAztecPrivate(uint256 amount, bytes32 secretHash) external nonReentrant returns (bytes32 key, uint256 index);
function withdraw(address recipient, uint256 amount, bool withCaller, Epoch epoch, uint256 numCheckpointsInEpoch, uint256 leafIndex, bytes32[] calldata path) external nonReentrant;
```
Bodies are **content-hash-identical** to the forked portal (not byte-identical — A5d): `l2Bridge → L2_HUB`, `underlying → underlying()`; the three `abi.encodeWithSignature` preimages untouched — `ContentHash.t.sol` and `PortalRoundtripFuzz.t.sol` pass with zero vector edits. Inserted, all content-hash-neutral: `if (FACTORY.depositsPaused()) revert Paused()` / `withdrawsPaused()`; `require(amount <= type(uint128).max)` (D13); exact-in on deposit `require(bal(after) − bal(before) == amount)` (D5) and exact portal-debit on withdraw (D37). Zero storage; no `initialize`.

**`PortalFactory`** (`is Ownable2Step`; owner == guardian; `renounceOwnership` reverts)

```solidity
event PortalCreated(address indexed token, address indexed portal, bytes32 nameWord, bytes32 symbolWord, uint8 decimals, bytes32 registerKey, uint256 registerIndex);
event PauseChanged(bool deposits, bool withdraws);
TokenPortalImpl public immutable IMPLEMENTATION;  IInbox public immutable INBOX;  uint256 public immutable ROLLUP_VERSION;  bytes32 public immutable L2_HUB;
bytes32 public constant REGISTER_SECRET_HASH = <compute_secret_hash([0]), keystone-pinned>;   // D10
struct Registration { address portal; uint8 decimals; uint64 registerIndex; bytes32 nameWord; bytes32 symbolWord; bytes32 registerKey; }   // D28, 4 slots
mapping(address token => Registration) public registrations;  mapping(address portal => address token) public tokenOf;
function portalOf(address token) public view returns (address);  // registrations[token].portal
bool public depositsPaused;  bool public withdrawsPaused;
constructor(IRegistry registry, bytes32 l2Hub, address guardian);   // deploys IMPLEMENTATION (D7)
function salt(address token) public pure returns (bytes32);          // bytes32(uint256(uint160(token)))  (D9)
function predictPortal(address token) public view returns (address); // Clones.predictDeterministicAddressWithImmutableArgs(IMPLEMENTATION, abi.encodePacked(token), salt(token))
function createPortal(address token) public returns (address portal); // idempotent (D6)
function setPaused(bool deposits, bool withdraws) external onlyOwner;
```
`createPortal` first call: `require(token.code.length > 0)`; metadata via gas-capped `staticcall`s with bounded returndata copies — `decimals()` **required** (`returndatasize == 32` — a `string` return's offset word must not read as 32 decimals — value ≤ 255, else `revert NoDecimals()`), `name()`/`symbol()` accept `string` or `bytes32` (MKR-style), default empty; sanitize to 31 printable-ASCII bytes (D8); clone; `INBOX.sendL2Message(L2Actor(L2_HUB, ROLLUP_VERSION), registerHash, REGISTER_SECRET_HASH)`; emit. `registerHash = Hash.sha256ToField(abi.encodeWithSignature("register(address,address,bytes32,bytes32,uint8)", token, portal, nameWord, symbolWord, decimals))`; write `registrations[token]` (incl. the returned `key` + `index`) + `tokenOf[portal]`; emit. Metadata is sampled once at first creation — a front-runner cannot change portal or token identity, only freeze the first-observed sanitized words.

### Non-obvious mechanics

- **Clone initcode** (OZ 5.7.0 `Clones.sol:279-293`): `0x61 ‖ uint16(20 + 0x2d) ‖ 3d81600a3d39f3363d3d373d3d3d363d73 ‖ impl ‖ 5af43d82803e903d91602b57fd5bf3 ‖ erc20` = 75 bytes; runtime 65 bytes; `portal = keccak256(0xff ‖ factory ‖ salt ‖ keccak256(initcode))[12:]`. Keystone: Solidity `predictPortal` ↔ TS `predictPortal` on a fixed vector.
- **Register word** (D8): `nameWord = bytes32(uint256(uint248(bytes31(sanitized))))` = `0x00 ‖ b0..b30`, equal to Noir `FieldCompressedString::from_string(name).value` as a big-endian field; TS derives `str<31>` args from the word, never from UTF-8.
- **Register hash**: `sha256ToField(selector4 ‖ pad32(erc20) ‖ pad32(portal) ‖ nameWord ‖ symbolWord ‖ pad32(decimals))`, 164 bytes; 4th keystone vector next to the three in `ContentHash.t.sol` / `keystone/src/main.nr` / `content-hash.test.ts`.
- **Hub token address**: `AztecAddress::compute(PublicKeys::default(), PartialAddress::compute(TOKEN_CLASS, salt = erc20, init_hash = poseidon2([selector(constructor_with_minter), hash_args(65 fields)], DOM_SEP__INITIALIZER), deployer = HUB, immutables_hash = 0))`; keystone: a TXE test registers a fixed vector and asserts `token_for(erc20)`; `hub-token.test.ts` asserts the same literal.
- **Genesis (D2, D32)**: publish the Token + hub classes (idempotent) → `factory = getContractAddress({from: deployer, nonce})` → `hub = derive(hubClass, salt = Fr(factory), [tokenClassId, factory, guardian])` → deploy the factory (nonce asserted at send; mismatch = journal + abort, nothing else exists yet) → deploy the hub instance (idempotent) → assert `factory.L2_HUB() == hub` and `hub.l1_factory == factory` before any pre-create.
- **Gas share (D14)**: `fuelFj = max(minFuelFj, txTarget × fjPerTx)`; `rate = quote(probe) / probe`; `fuelAmount = ceil(fuelFj / rate × (1 + slippageBps/1e4))`, capped at 50 % of `amount`; the real slice is re-quoted for the signed `minFuelOutput`.
- **Route discovery (D15)**: one Multicall3 `aggregate3` of dust `quoteExactInputSingle` per candidate; "initialized ≠ liquid"; best output wins; all fail ⇒ `no-route`; RPC failure ⇒ `unavailable` (distinct UI state).

## Security & Adversarial Considerations

- **Threat model**: any L1/L2 user, any token author, the list origin, a compromised guardian key, a compromised **router owner** key (`setSwapTarget` rotation invalidates pending witnesses; `sweep` moves only stranded residue — no user funds at rest), a compromised RPC. Assets: per-token reserves (isolated per clone), L2 supplies, in-flight messages, browser state.
- **Poisoning**: impossible by construction — the hub consumes `register` only from the immutable factory, `mint_*` only from `portal_of[token]` written once from that message; portal = f(factory, impl, erc20); L2 token = f(hub, class, erc20, attested words). A front-run `createPortal` yields the same portal and L2 token; it can only freeze the first-observed metadata (cosmetic). The D1 tuple test (P1) pins the whole chain end to end.
- **Metadata**: attacker-controlled strings → gas-capped `staticcall`, bounded returndata copy, 31-byte ASCII sanitization (D8); rendered as text nodes only (no `v-html`); same-symbol tokens distinguished by address; sprite keyed by address (D25). `decimals` missing or > 255 ⇒ no portal; any `u8` accepted, all math in base units (D13).
- **Token behaviors**: FoT rejected on deposit (D5) and the reserve is protected on withdraw by exact portal-debit (D37) — a tax a token enables *later* is paid by the withdrawer, never by the reserve; rebasing unsupported — positive rebases accrue to the portal, negative under-collateralize; documented and shown as a caution for pasted tokens; ERC-777 hooks meet `ReentrancyGuardTransient` + checks-effects; `amount > u128` rejected (D13).
- **Guardians (D3 + D40, owner-confirmed)**: L1 guardian = pause deposits/withdraws, **global**; L2 guardian = pause exits only. A stolen L1 key can freeze every exit indefinitely (ransom-grief, no theft); exits **burn before FINISH**, so an L1 pause raised between burn and withdraw leaves the L2 side burned until unpause — pausing L2 exits at the same time stops new burns, and the app preflights both bits, states the order in the review, and never discards the record; a hub bug can be frozen but not recovered — the hub is immutable and ownerless, so recovery = new generation with reserves stranded behind the pause. `Ownable2Step` + disabled renounce; testnet guardian = a dedicated recorded EOA; a multisig before mainnet (recorded for `/harden security`). The pause-after-burn window (for exits already burned when the L1 pause lands) and the global blast radius are intrinsic to D3 and **owner-accepted**.
- **Hub systemic risk**: one L2 contract serves every token and every L2 token shares one class — a hub auth/portal-selection/mint bug or a Token-class bug is **generation-wide**; per-clone L1 isolation contains only *malicious ERC-20 behavior* to that token's reserve. Mitigations: minimal surface, F-007 body verbatim, sole-consumer tripwire with named sites, cross-token TXE tests (authwit replay, mismatched exits, second-leaf registration). **Mainnet decision recorded for `/harden security` (blocking)**: the recovery/migration story for a broken generation (the L2 exit-only pause is now in, D40).
- **Router**: portal derived on-chain per entrypoint (D23) before any pull; witness binds portal/token/amounts/recipients/route/swapTarget; fuel-only requires zero recipient + zero portal; hookless routes enforced on-chain (`_validateRoute`) and asserted off-chain before signing; signed `minFuelOutput` is the floor. **Accepted risk — a compromised RPC**: quotes and slippage are relative to the wallet's own RPC, so a false quote can authorize a poor floor bounded only by the 50 % slice cap; there is no independent price source inside the CSP. This is the same trust the user already places in that RPC for balances; the review's Details line shows the effective rate. Live cross-binding readbacks (D38) close the other half — a router bound to a foreign factory.
- **Token list**: single pinned origin, HTTPS, CORS verified, `redirect: "error"`, streamed byte cap before parsing, zod at the boundary (count/length caps, chainId filter), no `logoURI` ever fetched or rendered, only the validated subset persisted, cache re-validated on read, fails closed to cache → manifest tokens. A poisoned list can promote a counterfeit address under a familiar name — list entries are labeled untrusted, the address is always shown in Details, and identity (portal, L2 token) never comes from the list. CSP `connect-src` widened by exactly one host, `img-src` unchanged.
- **Journal/backup**: union schema (D18) — a `token`/`token+gas` record without a token block is invalid; `deploymentMatches` re-derives the portal; backups reject header/seal mismatches including `token`.
- **Wallet grants (D22)**: exact-address scopes only; the per-token re-grant is a visible wallet prompt at Sign & send; no wildcard `burn_*`. The tools app touches no wallet code (D34).
- **Genesis (D2)**: no roles; a nonce race aborts before the hub exists; a front-run identical hub/class is idempotent success after readback; `factory.L2_HUB()`/`hub.l1_factory` cross-checked before pre-create.
- **Supply chain / least privilege**: viem only (already present); Multicall3 canonical address from `viem/chains`; OZ pinned by commit in CI (`cab19933` = **5.7.0**, has `ReentrancyGuardTransient`); TXE server deps under a committed lockfile (D24); CI compiles the hub and asserts parity with the committed artifact (D33); sprite SVGs committed + svgo-stripped; root lockfile frozen; CI keeps `permissions: contents: read`; fork and TXE jobs stay secret-free.
