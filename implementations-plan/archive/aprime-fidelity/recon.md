## Summary

The reskin changed tokens and fonts but kept the earlier anatomy, so the app reads as a repaint rather than as the A′ boards. The owner's four examples each trace to concrete causes:

- **"Changing the logo."** The 8×8 mark is pixel-identical to the boards. The wordmark renders lowercase `unleashed` because the Sixtyfour subset has no capitals (G05).
- **"The icons on the navbar."** The rail nav icons match. What diverges is:
  - the theme control, which is a cycling ghost button where the boards show a 3-choice radiogroup (G04);
  - the rail count, which is a bare number where the boards show a magenta chip (G30);
  - the dock toggle, drawn with a 16px chevron (G31);
  - app-wide, 12 missing Pixelarticons (G01), plus 38 icons rendered at 16px, a size the pixel grid does not allow (G26).
- **"Token list / icons."**
  - A scoped CSS leak turns the mint strip raised and centred and makes its buttons invisible (G03).
  - Every row is a filled slab where the boards rest rows transparent (G08).
  - Token marks are hashed-hue stripes where the boards use flat brand tiles (G07).
  - The search icon is a stroked vector (G80), and the mint and Add buttons lack icons (G79, G82).
- **"Wallet modal over static."** The static filter runs in linearRGB, so the scrim and the veil render as pale grey haze where the boards show dark TV noise (G02). The picker rows also keep the earlier anatomy: an empty tile, an ink "Connect" button, no ×, no id line (G06, G65).

Beyond those four, the largest structural divergences are:
- **In-flight:** no overall phase bar, no locked direction row, no log (G09–G11).
- **Activity cards:** no status chips or needs-you amber, and a "✓ Bridged" stamp (G12, G13, G16, G25). The semantics are inverted: failures wear the amber edge the boards reserve for needs-you, needs-you cards wear nothing, and no card says "Lost signal" (G148).
- **Receipt:** missing proof print, detail list and account line (G39–G41).
- **Faucet cards:** Mono headings, side-by-side wells, a lilac chip at the bottom (G19–G22).
- **Mobile:** a 44px dock column still eats the phone width (G17), and the step rail stays vertical (G18).

Several items are plain bugs, independent of taste:
- G03 mint strip leak
- G02 linearRGB static
- G14 Review marked done before it is visited
- G58 an other-account card tells the user to press a hidden Claim button
- G67 the verification modal never takes focus (Esc is dead)
- G68 a persisted open dock covers the whole phone screen
