## Security & Adversarial Considerations
- **Deploy→init window (F-001):** no CREATE2/atomic factory (it would ship stub bytecode — see ledger). The window between portal-deploy and `initialize` is closed by: the init-once guard (a front-run init locks the attacker's state, so the deployer MUST init in the immediately-following tx from the same EOA, ideally same block) + the read-back-abort (a hijacked init → script aborts, treats the portal as burned, redeploys a fresh generation). On testnet with tight sequencing the residual window is small; documented, not zero.
- **Per-attempt generation burn:** one-shot L2 wiring (`set_bridge`/`set_token`) means a failed attempt after wiring burns the whole generation. Mitigation: per-attempt full-generation salts + a **durable write-ahead attempt journal** (appended per receipt) as the authoritative resume artifact; if not cleanly resumable, bump the generation and redeploy. The canary (B-canary) rehearses this on a throwaway generation first.
- **Content-hash drift → strand:** deploy/verify uses the REAL `@aztec` `Hash`/`DataStructures`/interfaces (l1-contracts-root compile) — no stub surface on the production withdraw/outbox path. The shim is test-only. `ContentHash.t.sol` + keystone (CI-gated) + the canary deposit→claim are the backstop.
- **Supply chain:** the staged-into-`node_modules` deploy/verify root is mutable local state — run B6 from a clean lockfile-resolved checkout; the keccak pin authenticates only the vendored portal file, not the toolchain.
- **Candidate manifest TOCTOU + atomic swap:** the candidate is a same-directory sibling temp under `packages/faucet/public/` (randomized name, 0600) — NOT `mktemp -d` (a cross-device rename isn't atomic and can fail at activation); `fsync` + terminal atomic `rename(2)` is the swap.
- **Least-privilege key:** testnet key, env-only, never logged. The cutover is inherently single-hot-key (deployer = portal-init + proxy bootstrap); multisig deferred (user decision 4) — tracked residual. Etherscan verification is non-blocking so an off-chain outage can't consume a live attempt.
- **CI residual (user decision 2):** the required gate runs content-hash + L1 tests + keystone `nargo test`, NOT `aztec compile` of proxy/bridge — a post-merge Noir compile-break to those is unguarded; mitigated by the B3 local compile + dev discipline.
- **Abandoned old stack:** old portal/token/bridge stay exploitable but unreferenced + low-value testnet; old-token balances orphaned with no notice (accepted).
